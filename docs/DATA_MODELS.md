# Data Models

> Contract version **0.1.0 (draft)**. The canonical TypeScript definitions are in [FRONTEND_BACKEND_CONTRACT.md §3](FRONTEND_BACKEND_CONTRACT.md#3-models). This document explains them. If the two ever disagree, the contract wins and this file is a bug.

## How to read this document

**Origin column**

| Label | Meaning |
|---|---|
| **source** | Comes from NASA/IRSA metadata or files (possibly normalized into our naming/units). We do not guarantee the archive always provides it, so these fields are optional unless noted. |
| **derived** | Computed by our backend from source data. |
| **app** | Generated by our application (IDs, our own timestamps, user content). |
| **external** | Comes from a non-NASA service (name resolver, LLM). |

**Req column**: `R` = always present. `O` = omitted when not available (never `null`). Arrays are always present (`R`), possibly empty.

**Example data.** Every JSON example below is **illustrative**. Numbers, IDs, release names, and flag codes are made up for documentation and are not real SPHEREx data. Real archive field names and flag definitions must be confirmed against IRSA's SPHEREx documentation when the backend is built. The `sourceMetadata` passthrough exists so we never have to invent archive field names in the typed model.

## SkyCoordinate (shared)

ICRS position in decimal degrees. Origin depends on the parent model.

| Field | Type | Req | Notes |
|---|---|---|---|
| `raDeg` | number | R | [0, 360) |
| `decDeg` | number | R | [-90, 90] |

## Availability (shared)

Describes whether a resource is ready. Origin: **derived**/**app** (our backend's processing state).

| Field | Type | Req | Notes |
|---|---|---|---|
| `status` | `"available" \| "processing" \| "unavailable" \| "failed"` | R | |
| `statusReason` | string | O | Present whenever `status !== "available"` |
| `retryAfterSeconds` | number | O | Polling hint |

## QualityFlag (shared)

| Field | Type | Req | Origin | Notes |
|---|---|---|---|---|
| `code` | string | R | source or derived | For `origin: "source"`, mirrors the archive's flag as reported. Not a closed list. |
| `severity` | `"info" \| "warning" \| "critical"` | R | derived | Our classification of the flag's impact. Mapping is our decision, not NASA's. |
| `description` | string | R | derived | Plain-language text we write |
| `origin` | `"source" \| "derived"` | R | derived | Whether the flag came from the archive or from our own checks |

## 1. AstronomicalObject

**Purpose.** A searchable thing in the sky the user investigates (star, galaxy, nebula, or an arbitrary position).

| Field | Type | Req | Origin |
|---|---|---|---|
| `objectId` | string | R | app |
| `name` | string | R | external (resolver) or app if user-entered coordinates |
| `aliases` | string[] | R | external |
| `coordinates` | SkyCoordinate | R | external |
| `objectType` | string | O | external (free text, not an enum) |
| `resolver` | `{ name: string; identifier?: string }` | R | app (records which service answered) |
| `observationSummary` | `{ count: number; firstObservedAt?: ISODateTime; lastObservedAt?: ISODateTime }` | O | derived from IRSA query results |

```json
{
  "objectId": "obj_8f3a21",
  "name": "M 51",
  "aliases": ["NGC 5194", "Whirlpool Galaxy"],
  "coordinates": { "raDeg": 202.4696, "decDeg": 47.1952 },
  "objectType": "Galaxy",
  "resolver": { "name": "example-resolver", "identifier": "M 51" },
  "observationSummary": {
    "count": 14,
    "firstObservedAt": "2025-05-02T11:04:00Z",
    "lastObservedAt": "2025-10-21T02:47:30Z"
  }
}
```

## 2. Observation

**Purpose.** One SPHEREx observation relevant to an object: where, when, what wavelengths, and its quality. Metadata only; the picture is `ObservationImage`.

| Field | Type | Req | Origin | Notes |
|---|---|---|---|---|
| `observationId` | string | R | app | Stable across requests; mapping to the archive ID is internal (OD-14) |
| `objectIds` | string[] | R | derived | Objects whose position falls inside the footprint |
| `irsaObservationId` | string | O | source | The archive's identifier, if the archive provides one |
| `dataRelease` | string | O | source | Release identifier as reported |
| `observedAt` | ISODateTime | O | source | Exposure start, if provided |
| `center` | SkyCoordinate | R | source (normalized) | Image center |
| `footprint` | SkyCoordinate[] | O | derived | Polygon from WCS + image size |
| `detector` | string | O | source | As reported |
| `wavelengthRangeUm` | `{min, max}` | O | derived | From header/spectral calibration information; see pipeline doc |
| `image` | Availability | R | derived | Is a viewable image obtainable |
| `qualityFlags` | QualityFlag[] | R | source/derived | |
| `qualitySummary` | `"good" \| "degraded" \| "poor" \| "unknown"` | R | derived | Rule-based roll-up of flags (rules documented in backend) |
| `sourceMetadata` | Record<string, unknown> | O | source | Raw archive values, display-only |

```json
{
  "observationId": "obs_00a91c",
  "objectIds": ["obj_8f3a21"],
  "irsaObservationId": "EXAMPLE-ID-0001",
  "dataRelease": "example-release-1",
  "observedAt": "2025-07-14T03:22:10Z",
  "center": { "raDeg": 202.51, "decDeg": 47.22 },
  "detector": "example-detector-3",
  "wavelengthRangeUm": { "min": 1.62, "max": 1.97 },
  "image": { "status": "available" },
  "qualityFlags": [
    { "code": "EXAMPLE_FLAG", "severity": "warning", "description": "Part of the field is masked.", "origin": "source" }
  ],
  "qualitySummary": "degraded",
  "sourceMetadata": { "exampleHeaderKey": "exampleValue" }
}
```

## 3. ObservationImage

**Purpose.** A display-ready rendering of one observation plus the information needed to draw it correctly. The frontend never reads FITS.

| Field | Type | Req | Origin |
|---|---|---|---|
| `observationId` | string | R | app |
| `availability` | Availability | R | derived |
| `imageUrl` | string | O (R when available) | derived (rendered raster) |
| `width`, `height` | number | O (R when available) | derived |
| `stretch` | `{ mode, lowValue, highValue, unit? }` | O | derived |
| `wcs` | WcsSummary | O | source (FITS WCS keywords, reduced) + derived (`pixelScaleArcsec`, `approximate`) |
| `qualityMaskUrl` | string | O | derived |
| `fitsDownloadUrl` | string | O | derived (points to the cached raw file) |
| `generatedAt` | ISODateTime | R | app |

`WcsSummary`: `ctype1?`, `ctype2?` (source), `crval`, `crpix`, `cd` (source), `pixelScaleArcsec?` (derived), `approximate` (derived; `true` if the full solution has terms not represented here).

```json
{
  "observationId": "obs_00a91c",
  "availability": { "status": "available" },
  "imageUrl": "/media/images/obs_00a91c_asinh.png",
  "width": 1024,
  "height": 1024,
  "stretch": { "mode": "asinh", "lowValue": 0.1, "highValue": 42.0, "unit": "example-unit" },
  "wcs": {
    "ctype1": "RA---TAN", "ctype2": "DEC--TAN",
    "crval": [202.51, 47.22], "crpix": [512, 512],
    "cd": [[-1.7e-3, 0], [0, 1.7e-3]],
    "pixelScaleArcsec": 6.2,
    "approximate": true
  },
  "qualityMaskUrl": "/media/masks/obs_00a91c.png",
  "generatedAt": "2026-11-14T10:00:00Z"
}
```

## 4. SpectralData

**Purpose.** A spectrum (flux vs wavelength) for a sky position, assembled by the backend across observations. The mission defines a fixed set of spectral bands (documented as 102; confirm against official docs); a given position may not have all of them.

| Field | Type | Req | Origin |
|---|---|---|---|
| `spectrumId` | string | R | app |
| `objectId` | string | R | app |
| `availability` | Availability | R | derived |
| `position` | SkyCoordinate | R | derived (defaults to object position) |
| `apertureRadiusArcsec` | number | O | derived |
| `extractionMethod` | string | R | derived |
| `wavelengthUnit` | `"um"` | R | derived |
| `fluxUnit` | string | R | source (as given by the archive) or derived (if converted; then stated in `extractionMethod`) |
| `uncertaintyBasis` | string | O | derived |
| `points` | SpectralPoint[] | R | see below |
| `expectedBandCount` | number | O | derived (mission reference) |
| `warnings` | string[] | R | derived |
| `generatedAt` | ISODateTime | R | app |

**SpectralPoint**

| Field | Type | Req | Origin |
|---|---|---|---|
| `wavelengthUm` | number | R | source/derived (band center) |
| `wavelengthMinUm`, `wavelengthMaxUm` | number | O | source/derived |
| `bandIndex` | number | O | derived (1-based) |
| `available` | boolean | R | derived |
| `unavailableReason` | string | O | derived |
| `flux` | number | O (omitted if `available: false`) | derived (measured by us from source pixels) |
| `fluxUncertainty` | number | O | derived |
| `qualityFlags` | QualityFlag[] | R | source/derived |
| `observationId` | string | O | app |
| `observedAt` | ISODateTime | O | source |

```json
{
  "spectrumId": "spec_51c2d0",
  "objectId": "obj_8f3a21",
  "availability": { "status": "available" },
  "position": { "raDeg": 202.4696, "decDeg": 47.1952 },
  "apertureRadiusArcsec": 12,
  "extractionMethod": "Aperture photometry, 12 arcsec radius, local background annulus (example description).",
  "wavelengthUnit": "um",
  "fluxUnit": "example-flux-unit",
  "uncertaintyBasis": "Propagated from the archive's uncertainty information.",
  "points": [
    { "wavelengthUm": 0.78, "bandIndex": 1, "available": true, "flux": 3.1, "fluxUncertainty": 0.2,
      "qualityFlags": [], "observationId": "obs_00a91c", "observedAt": "2025-07-14T03:22:10Z" },
    { "wavelengthUm": 0.82, "bandIndex": 2, "available": false,
      "unavailableReason": "No usable observation covering this position in this band.", "qualityFlags": [] }
  ],
  "expectedBandCount": 102,
  "warnings": ["Points come from different observation dates; source variability is not corrected."],
  "generatedAt": "2026-11-14T10:05:00Z"
}
```

## 5. Measurement

**Purpose.** One quantitative result our backend computed, with its uncertainty and method. This is what the AI and UI cite as numbers.

| Field | Type | Req | Origin |
|---|---|---|---|
| `measurementId` | string | R | app |
| `kind` | `"aperture_flux" \| "flux_change" \| "angular_separation" \| "region_statistics"` | R | derived |
| `value` | number | R | derived |
| `unit` | string | R | derived |
| `uncertainty` | number | O | derived |
| `uncertaintyBasis` | string | O | derived |
| `observationIds` | string[] | R | app |
| `region` | `{ center: SkyCoordinate; radiusArcsec: number }` | O | derived/user-selected |
| `method` | string | R | derived |
| `qualityFlags` | QualityFlag[] | R | source/derived |
| `warnings` | string[] | R | derived |
| `createdAt` | ISODateTime | R | app |

```json
{
  "measurementId": "meas_7be114",
  "kind": "flux_change",
  "value": 0.8,
  "unit": "example-flux-unit",
  "uncertainty": 0.3,
  "uncertaintyBasis": "Quadrature sum of per-observation aperture uncertainties.",
  "observationIds": ["obs_00a91c", "obs_00b02e"],
  "region": { "center": { "raDeg": 202.4696, "decDeg": 47.1952 }, "radiusArcsec": 12 },
  "method": "Aperture photometry difference, 12 arcsec, matched aperture, after alignment.",
  "qualityFlags": [],
  "warnings": ["Change is within 3 sigma of the uncertainty."],
  "createdAt": "2026-11-14T10:07:00Z"
}
```

## 6. ComparisonResult

**Purpose.** The outcome of comparing two observations: whether they may be compared, aligned images for blink/overlay/difference, and any measurements.

| Field | Type | Req | Origin |
|---|---|---|---|
| `comparisonId` | string | R | app |
| `mode` | `"blink" \| "overlay" \| "difference"` | R | app (user choice) |
| `baseObservationId`, `targetObservationId` | string | R | app |
| `availability` | Availability | R | derived |
| `compatibility.verdict` | `"comparable" \| "comparable_with_caveats" \| "not_comparable" \| "unknown"` | R | derived |
| `compatibility.checks[]` | `{ name, result, detail }` | R | derived |
| `alignment` | `{ method: string; residualArcsec?: number }` | O | derived |
| `baseImage`, `targetImage` | ObservationImage | O | derived (resampled to a common grid) |
| `differenceImage` | ObservationImage | O (only `difference` mode) | derived |
| `measurements` | Measurement[] | R | derived |
| `warnings` | string[] | R | derived |
| `createdAt` | ISODateTime | R | app |

Check `name` values: `wavelength`, `calibration`, `alignment`, `quality`, `dataRelease`, `footprint`. `result` values: `pass`, `warn`, `fail`, `notEvaluated`.

```json
{
  "comparisonId": "cmp_3d90aa",
  "mode": "difference",
  "baseObservationId": "obs_00a91c",
  "targetObservationId": "obs_00b02e",
  "availability": { "status": "available" },
  "compatibility": {
    "verdict": "comparable_with_caveats",
    "checks": [
      { "name": "wavelength", "result": "pass", "detail": "Wavelength ranges overlap over the compared region." },
      { "name": "calibration", "result": "notEvaluated", "detail": "Calibration equivalence between releases is not verified." },
      { "name": "alignment", "result": "pass", "detail": "Residual 0.4 arcsec." },
      { "name": "quality", "result": "warn", "detail": "Target has a masked area overlapping the region." }
    ]
  },
  "alignment": { "method": "WCS reprojection to base grid (example)", "residualArcsec": 0.4 },
  "baseImage": { "observationId": "obs_00a91c", "availability": { "status": "available" }, "imageUrl": "/media/cmp_3d90aa/base.png", "width": 1024, "height": 1024, "generatedAt": "2026-11-14T10:06:00Z" },
  "targetImage": { "observationId": "obs_00b02e", "availability": { "status": "available" }, "imageUrl": "/media/cmp_3d90aa/target.png", "width": 1024, "height": 1024, "generatedAt": "2026-11-14T10:06:00Z" },
  "differenceImage": { "observationId": "obs_00b02e", "availability": { "status": "available" }, "imageUrl": "/media/cmp_3d90aa/diff.png", "width": 1024, "height": 1024, "generatedAt": "2026-11-14T10:06:00Z" },
  "measurements": [],
  "warnings": ["Difference images show residuals from alignment and noise as well as real change."],
  "createdAt": "2026-11-14T10:06:00Z"
}
```

## 7. Investigation

**Purpose.** A user's saved workspace: notes, bookmarks, activity history, and the conversation. Entirely **app**-generated; contains no archive data except by reference (IDs).

| Field | Type | Req | Origin | Notes |
|---|---|---|---|---|
| `investigationId` | string | R | app | |
| `title` | string | R | app (user) | |
| `objectId` | string | O | app | Primary object |
| `createdAt`, `updatedAt` | ISODateTime | R | app | |
| `notes` | Note[] | R | app (user) | `{ noteId, text, createdAt, observationId?, comparisonId? }` |
| `bookmarks` | Bookmark[] | R | app (user) | `{ bookmarkId, targetType, targetId, label?, createdAt }` |
| `history` | InvestigationEvent[] | R | app (frontend records) | `{ eventId, type, targetId?, at }` |
| `messages` | ChatMessage[] | R | app | **Server-managed.** Ignored on PUT. |

```json
{
  "investigationId": "inv_19ce02",
  "title": "Brightness change in M 51",
  "objectId": "obj_8f3a21",
  "createdAt": "2026-11-14T09:50:00Z",
  "updatedAt": "2026-11-14T10:08:00Z",
  "notes": [{ "noteId": "note_1", "text": "Check masked region before trusting the difference.", "createdAt": "2026-11-14T10:08:00Z", "comparisonId": "cmp_3d90aa" }],
  "bookmarks": [{ "bookmarkId": "bm_1", "targetType": "comparison", "targetId": "cmp_3d90aa", "label": "Main comparison", "createdAt": "2026-11-14T10:07:30Z" }],

    { "eventId": "ev_1", "type": "object_opened", "targetId": "obj_8f3a21", "at": "2026-11-14T09:50:05Z" },

  ],
  "messages": []
}
```

## 8. ChatMessage

**Purpose.** One message in the companion conversation.

| Field | Type | Req | Origin |
|---|---|---|---|
| `messageId` | string | R | app |
| `role` | `"user" \| "assistant"` | R | app |
| `content` | string | R | user text, or **external (LLM)** for assistant |
| `createdAt` | ISODateTime | R | app |
| `context` | ChatContext | O (user messages) | app (frontend describes what the user is looking at) |

**ChatContext** (all optional): `activeView`, `objectId`, `observationIds`, `comparisonId`, `spectrumId`, `measurementIds`, `selection { observationId, sky?, radiusArcsec? }`.

```json
{
  "messageId": "msg_u1",
  "role": "user",
  "content": "Is the brightening real?",
  "createdAt": "2026-11-14T10:09:00Z",
  "context": { "activeView": "comparison", "objectId": "obj_8f3a21", "comparisonId": "cmp_3d90aa" }
}
```

## 9. AIResponse

**Purpose.** The companion's answer plus structured companions the UI can render separately from the prose: what it was based on, caveats, and suggested next steps. `message.content` is **AI-generated explanation**, not data.

| Field | Type | Req | Origin |
|---|---|---|---|
| `message` | ChatMessage (`role: "assistant"`) | R | external (LLM) wrapped by app |
| `references` | `{ targetType, targetId }[]` | R | derived (backend records which results it was given) |
| `caveats` | string[] | R | derived (backend-enforced; not left to the LLM alone) |
| `suggestedActions` | `{ kind, label, targetId?, params? }[]` | R | derived |
| `availability` | Availability | R | derived |

```json
{
  "message": {
    "messageId": "msg_a1",
    "role": "assistant",
    "content": "The measured change is 0.8 ± 0.3 (example units), which is under three times its uncertainty, so this comparison does not establish a real brightening. Part of the target image is masked near the source.",
    "createdAt": "2026-11-14T10:09:04Z"
  },
  "references": [
    { "targetType": "comparison", "targetId": "cmp_3d90aa" },
    { "targetType": "measurement", "targetId": "meas_7be114" }
  ],
  "caveats": ["Calibration equivalence between these observations was not verified."],
  "suggestedActions": [
    { "kind": "open_observation", "label": "View the masked target observation", "targetId": "obs_00b02e" }
  ],
  "availability": { "status": "available" }
}
```

## Cross-model integrity rules

1. Any ID appearing in a `references`, `observationIds`, `targetId`, `objectIds`, or `ChatContext` must be resolvable by the corresponding GET endpoint.
2. `ComparisonResult.baseImage`/`targetImage`/`differenceImage` have the same `width` and `height` when all are present.
3. `SpectralPoint.flux` is present if and only if `available` is `true`.
4. `Observation.image.status` and the `availability.status` returned by `GET /observations/{id}/image` agree (aside from transient `processing`).
5. Units: a `Measurement` taken from a `SpectralData` or a `ComparisonResult` uses the same unit string as the data it came from.
